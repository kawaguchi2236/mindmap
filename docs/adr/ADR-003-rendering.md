# ADR-003: マインドマップの描画方式

## ステータス

採用（2026-09-13）／決定者: 担当 A（基盤・エディタ）

---

## 背景

Phase 1 のエディタに必要なのは、無限キャンバス・パン・ズーム・中央へ戻る・ノードのドラッグ・親子の接続線・折りたたみ・選択表示、そして**キーボードだけで完結する操作**（CLAUDE.md §8 §9）。性能目標は 500 ノードで実用、1000 ノードが努力目標（§10）。

`CLAUDE.md` §32 ADR-003 は「ライブラリの制約がコア UX と衝突しない限り、グラフ/キャンバスエンジンを一から作るより成熟したライブラリを使え」と定めている。

## 調査結果

| | React Flow (`@xyflow/react` v12) | 自前実装（CSS transform + SVG） |
|---|---|---|
| パン・ズーム | 組み込み。慣性・ピンチ・境界も面倒を見る | 自前。行列とイベントを全部書く |
| ノードのドラッグ | 組み込み（ズーム倍率の補正込み） | 自前。ズーム中のドラッグでずれやすい |
| 接続線 | 組み込み。ノード移動に追従 | 自前。ベジェ計算とアンカー位置を書く |
| カスタムノード | 任意の React コンポーネント | 同じ |
| ツリーレイアウト | **無い**（dagre/elk を足すか自前） | 自前 |
| キーボード操作 | 独自ショートカットを持つ（**こちらと衝突する**） | 衝突しない |
| 500 ノード | 実績あり | 素直に書けば問題ない |
| PNG 書き出し | `getNodesBounds` + `getViewportForBounds` で全体出力する定石がある | 自前 |
| ライセンス | MIT | — |

## 決定

**`@xyflow/react` v12 を土台に使い、その上に自前のレイヤーを載せる。**

ライブラリに任せる: ビューポート（パン・ズーム・fitView）、ノードのドラッグ、エッジ描画、カスタムノードの仕組み。

自前で書く（`src/features/editor/`）:

- `layout.ts` … 親から右へ伸びる横型マインドマップの自動レイアウト。**dagre / elk は入れない**（木のレイアウトは素直に書ける。§19「小さな機能のために大きな依存を入れない」）。
- `reducer.ts` / `history.ts` / `tree.ts` / `clipboard.ts` … 状態遷移・Undo/Redo・木操作・コピー&ペースト。**DOM に依存しない純粋関数**にして、ここをテストで固める。
- `useKeyboard.ts` … CLAUDE.md §8 のショートカット表。**React Flow 自身のキーボードショートカットは無効化する**（`deleteKeyCode={null}` 等）。これが唯一の衝突点で、無効化で解消できる。

## 理由

- ズーム中のドラッグ座標補正・ビューポート行列・エッジの追従は、自前で書くとバグが出やすく、**それ自体は製品の差別化にならない**。ここをライブラリに任せる価値が最も大きい。
- 逆に、キーボード操作とレイアウトは**この製品の中身そのもの**（§8「キーボードUXは第一級の要件」）なので、ライブラリの都合に合わせず自前で持つ。
- PNG 全体書き出し（Phase 1 の要件、§16）に定石があることは、担当 B の作業を軽くする。

## 影響

- エディタは `MindMapDocument` を受け取り `onChange` を返すだけの部品にする。**IndexedDB もクラウドも知らない**（§38「キャンバス描画をクラウド永続化に直結させない」）。
- ノードの `x` / `y` は自動レイアウトの結果を保存する。ユーザーがドラッグしたら、その座標で上書きする。
- 担当 B の PNG 書き出しは React Flow の API に依存してよい。エディタ側は `ReactFlowProvider` の内側で書き出せる形にしておく。
- メモ化・仮想化は入れない。**500 ノードで測ってから**判断する（§10）。

## 却下した選択肢

- **全部自前**: コア UX と衝突する制約が見つからないうちに一から書くのは §32 に反する。
- **dagre / elk-js の追加**: 木のレイアウトに汎用グラフレイアウトは過剰（§19 §37）。
- **他のマインドマップ専用ライブラリ**: キーボード操作とデータモデルを自分で握れないものは、この製品の一番大事な部分を明け渡すことになる。
